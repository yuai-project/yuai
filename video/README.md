# Yorido 紹介動画（Remotion）

YouTube 向け（1920×1080・48 秒）のデモ動画。冒頭で PC とスマホのトップ画面を並べ、スマホに寄ってから、
トップ → 相談フォーム（7問）→ 結果 → 記事 を、指の代わりの半透明の白い丸でタップしながら見せる。
見る人が追いつけるよう、操作を見せる問いは 1問目（相手が誰か）と 6問目（求めるサポート）だけにし、2〜5問目は左の一覧にチェックが付くだけにする。
6問目は「答えでヒントと記事が変わる」ことを伝える問いなので、選んだ答えをその場で大きく見せる。
7問目の自由記述は、AI と会話する機能に見えないよう、書かずに「See tips without writing」を押す。
結果画面は、人がスクロールするように指で4回はじいて（置く → 引き上げる → 離すと勢いで少し流れて止まる）、いちばん上から記事の一覧まで見せる。途中の部品（要点など）は飛び出させない。
記事が結果の中心なので、記事の一覧だけを飛び出させて大きく見せる。
見る人が酔わないよう、カメラは冒頭でスマホに寄ったあとは動かさない（操作中は白い丸と、スマホの中のスクロールだけが動く）。
はじめるボタン・記事の一覧・タップした記事は、スマホから切り出して左の見出しの下へ飛び出させ、大きく見せる（終わるともとの場所へ戻る）。
最後は記事をタップして新しいタブが開くところまで見せる。開いた先は他のサイトなので、ドメインだけ出して中身は映さない。
1問目と6問目の答え（フォームの選択肢）は、左へ飛ばさずにフォームの上でその場で大きくする。
左には短い見出しと質問の一覧だけを出し、説明はナレーションに任せる。
アプリ本体とは別の package.json を持ち、本体の依存には足していない。

- 発表・動画とも英語。アプリも英語版（`?lang=en`）で撮り、動画の見出しも英語
- スマホ枠の中身は、実際の画面を撮った画像（`public/shots/`）
- 白い丸を動かす先（ボタン・選択肢の位置）と、結果画面をどこまでスクロールするかも、撮影のときに実画面から測る（`public/shots/shots.json`）
- タップ音 `public/click.wav`（`scripts/make-click.mjs`）と BGM `public/bgm.wav`（`scripts/make-bgm.mjs`）は、
  スクリプトで合成したもの。外部の音源は使っていない。作り直しは `npm run sounds`
- BGM をフリー音源などに差し替えるときは `public/` に置き、`src/YoridoIntro.tsx` の `staticFile('bgm.wav')` を変える。
  ライセンス（YouTube で使えるか・クレジット表記）を確認すること
- 英語ナレーション原稿は [NARRATION.md](NARRATION.md)、YouTube 用の字幕は [captions.en.srt](captions.en.srt)。
  台本（`src/timeline.ts`）の秒数を変えたら、この2つの時間も合わせる

## 使い方

```bash
cd video
npm install
npm run studio   # プレビュー（ブラウザで開く）
npm run render   # out/yorido-intro.mp4 に書き出す
```

## 画面が変わったら撮り直す

UI を変えたら、リポジトリ直下で `npm run dev` を起動してから撮り直す。撮影には Mac の Google Chrome を使う。

```bash
cd video
npm run capture
```

答える内容（英語版の選択肢の文言）は `scripts/capture.mjs` の `ANSWERS`。自由記述は書かずに進む。

## どこを触ればいいか

| 変えたいもの | ファイル |
| --- | --- |
| 場面の秒数・左の見出し・白い丸（タップ）の動き・拡大率（`BASE_ZOOM`）・画面の囲み・飛び出させる部品 | `src/timeline.ts` |
| 見た目（スマホ枠・PC の枠・色・オープニング/エンディング・音量） | `src/YoridoIntro.tsx` |
| 音（クリック音・BGM の曲調） | `scripts/make-click.mjs`・`scripts/make-bgm.mjs` |
| 動画の長さ・サイズ | `src/timeline.ts` の `DURATION`、`src/Root.tsx` |
