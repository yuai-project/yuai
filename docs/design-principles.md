# デザインの原則と参考サイト

Yorido の見た目や画面の流れを考えるときの、判断のよりどころです。
ホーム・相談フォーム・結果画面を変える前に一度読んでください。
文言の決まりは [CLAUDE.md の「絶対に守るルール」](../CLAUDE.md)、色や余白は `src/index.css` の `@theme` が正です。

## 目指すこと

**サイトを閉じるとき、開く前より落ち着いた気持ちになっていてほしい。**

「次にできることが1つ分かる」は、そのための手段の一つです。

## Yorido は「診断コンテンツ」ではなく「診断サイト」

質問に答えると結果が出る、という形は診断コンテンツと同じです。
ただし Yorido は、悩んでいる人が使う道具であって、楽しんでもらうためのものではありません。

| 借りる（道具として必要） | 借りない（楽しませるための仕掛け） |
|---|---|
| 1画面に1つのことだけ聞く | 「あなたは〇〇タイプ」という結果発表 |
| 押しやすい選択肢、戻る・飛ばすの操作 | キャラクター、タイプ名、スコアやゲージ |
| 残りがどれくらいかの表示 | 結果を見せる前の演出やアニメーション |
| 結果の要点を最初にまとめる | 結果をシェアするカード（プライバシーの面でも避ける） |

相手をタイプに分類すると、ルール1（断定しない）とルール2（ラベリングしない）に反します。
サイトそのものを紹介する導線（ホームの「このサイトを伝える」）は問題ありません。

## デザインの原則

参考サイトを見比べて、「真似したくない」と感じた理由から取り出したものです。

1. **入口は1つにする** — 入口が2つあると迷う。ホームの主なボタンは「状況を入れてヒントをみる」だけにする
2. **何が得られるかを最初に具体的に見せる** — 最初の画面で、使うと何が見つかるのかが分からないと始めてもらえない
3. **ビジュアルで本題を押し下げない** — 大きな写真やカルーセルで、見出しや入口を画面の外に追い出さない
4. **人の顔を映さない** — 写真やイラストは、物や風景で雰囲気を伝える
5. **営利っぽさを出さない** — 会社紹介や SNS の告知を目立つ場所に置かない。運営の情報はフッターと「運営について」に置く
6. **意味の分からない演出をしない** — 何を表しているのか説明できない装飾やアニメーションは入れない
7. **1ページに1つのことを聞く** — 質問の形式はユビーや GOV.UK のように、1問ずつ答えてもらう

## Yorido では取り入れないところ

どれも各サイトの目的には合った作りです。ここでは、**Yorido の目的には合わない**と判断した点だけを書いています。

| サイト | Yorido では取り入れないところ |
|---|---|
| [こころの耳 ストレスセルフチェック](https://kokoro.mhlw.go.jp/check/) | 紙のような質感。表形式でまとめて答える質問の形式。最初のページでは、何が分かるのかの説明が控えめ |
| [Awarefy](https://www.awarefy.com/) | 企業サイトとしての情報が前に出ている構成。人物の写真 |
| [me-x](https://me-x.jp/) | 最初の画面では、使うと何が得られるのかがつかみにくい。季節感のあるアニメーション。SNS の告知が最初のほうに出てくる |

## 進め方

[3ステップで作る診断サイトのWebデザインプロセス（morry / BONO）](https://note.com/morry_design/n/n19450dfe1314) の流れを手本にしています。

1. **表現の方向性を決める** — 目的と雰囲気のキーワードを決め、参考サイトを二軸に並べたムードボードを作る
2. **白黒でパターンを出して土台を固める** — 色を付けずに、配置だけで3〜4案を並べて比べる
3. **全体を仕上げる** — 色・写真・文字サイズを、また案を並べて比べながら調整する

Yorido のムードボードの二軸は、次の2つを使います。

- 横軸：**楽しませる ⇔ 支える（道具）**
- 縦軸：**あたたかい ⇔ きちんと**

狙うのは「支える」側で、「あたたかい」と「きちんと」の間です。
上の参考サイトでいうと、あなたのいばしょが「きちんと」寄り、生きづらびっとが「あたたかい」寄りです。

途中でできた案は消さずに残し、並べて比べられるようにしておきます。
